# SpellGame — MVP 0.1: главное меню и экран персонажа

## 1. Цель

Создать минимальное настольное 2D-приложение на **Go + Ebitengine**, которое собирается в Windows `.exe` и запускается без установки Go или игрового движка.

При запуске открывается **главное меню**. Из него пользователь может перейти на экран **персонажа**, увидеть его изображение (на первом этапе допустим временный спрайт-заглушка) и характеристики, вернуться в меню или закрыть игру.

Это **первый вертикальный срез интерфейса**, а не боевой прототип. В рамках MVP не нужны движение по карте, противники, предметы, сохранения или сервер.

## 2. Технологический стек

- Язык: Go (версия, совместимая с выбранным релизом Ebitengine).
- Движок: Ebitengine v2.
- Графика: 2D, исходные PNG-ассеты; на первом этапе разрешены процедурные заглушки.
- Шрифты: TTF/OTF с лицензией, допускающей распространение; поддержка кириллицы.
- Данные персонажа: локальная структура Go; в дальнейшем возможен переход на JSON.
- Платформа MVP: Windows x64.
- Архитектура: одно локальное приложение без сетевого сервера и БД.

## 3. Пользовательские сценарии

### US-01. Запуск игры

1. Пользователь запускает `SpellGame.exe`.
2. Открывается окно игры размером 1280×720 (или с таким логическим разрешением).
3. Отображается главное меню, интерфейс не зависает и не требует подключения к интернету.

### US-02. Главное меню

Главное меню содержит:
- название **SpellGame**;
- кнопку **«Персонаж»**;
- кнопку **«Выход»**.

Кнопка «Персонаж» открывает экран персонажа. Кнопка «Выход» корректно завершает приложение.

### US-03. Просмотр персонажа

Экран персонажа содержит:
- имя: **Арканист**;
- класс: **Маг**;
- уровень: **1**;
- изображение персонажа в отдельной области (временный спрайт или нарисованная заглушка);
- список базовых характеристик с числовыми значениями;
- кнопку **«Назад»** для возврата в главное меню.

Начальные характеристики (демонстрационные, не окончательный игровой баланс):

| Характеристика | Значение |
|---|---:|
| Здоровье (HP) | 100 / 100 |
| Мана (MP) | 80 / 80 |
| Сила | 5 |
| Ловкость | 5 |
| Интеллект | 10 |
| Броня | 0 |
| Урон заклинаний | 12 |
| Шанс критического удара | 5% |
| Скорость передвижения | 100% |

Характеристики **только для просмотра**, изменение значений в UI в MVP не предусмотрено.

### US-04. Возврат

Нажатие «Назад» возвращает в главное меню без перезапуска приложения. Клавиша Escape на экране персонажа также возвращает в меню.

## 5. Архитектура

Принцип: **разделить данные персонажа, состояние интерфейса, обработку ввода и отрисовку**. Не вводить ECS или сложную систему событий для двух экранов.

```text
cmd/game/main.go
       │
       ▼
internal/app/game.go
       │
       ├── screens/menu.go
       ├── screens/character.go
       ├── ui/button.go
       ├── domain/character.go
       └── assets/assets.go
```

- `Game`: реализация интерфейса Ebitengine `Update`, `Draw`, `Layout`, хранение текущего экрана.
- `MenuScreen`: кнопки главного меню и переходы.
- `CharacterScreen`: отображение профиля и характеристик.
- `Button`: прямоугольная кнопка, hover, обработка клика **по нажатию**, а не каждый кадр удержания.
- `Character`: структура с данными персонажа, не зависит от Ebitengine.
- `Assets`: загрузка шрифта и спрайта либо резервная отрисовка заглушки.

Пример модели:

```go
type Character struct {
    Name       string
    Class      string
    Level      int
    Stats      Stats
}

type Stats struct {
    Health, MaxHealth int
    Mana, MaxMana     int
    Strength          int
    Dexterity         int
    Intelligence      int
    Armor             int
    SpellDamage       int
    CritChance        float64
    MoveSpeedPercent  float64
}
```

### Состояния

```text
[MainMenu] --Персонаж--> [CharacterScreen]
[MainMenu] --Выход-----> [ApplicationExit]
[CharacterScreen] --Назад/Escape--> [MainMenu]
```

Переходы должны выполняться без создания второго окна и без запуска отдельного процесса.

## 6. Графика и ассеты

В MVP **не блокируем разработку ожиданием AI-графики**.

1. Фон: однотонный тёмный или простой процедурный узор.
2. Кнопки и панели: рисуются средствами Ebitengine (прямоугольники, рамки, текст).
3. Персонаж: PNG с прозрачным фоном, если готов; иначе стилизованная процедурная заглушка с подписью.
4. В будущем PNG можно заменить на AI-сгенерированный спрайт без изменения модели характеристик и навигации.
5. Шрифт: встраиваем в сборку вместе с лицензией, если лицензия этого требует.

Использовать `go:embed` для упаковки файлов ресурсов в исполняемый файл. Не полагаться на относительный путь к рабочей директории пользователя.

## 8. Сборка Windows `.exe`

Команда для сборки **на Windows**:

```powershell
go mod tidy
go build -trimpath -ldflags="-H=windowsgui" -o dist/SpellGame.exe ./cmd/game
```

При сборке на Linux для Windows (если используемая версия Ebitengine и зависимости поддерживают cross-compilation без Cgo):

```bash
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 \
  go build -trimpath -ldflags='-H=windowsgui' \
  -o dist/SpellGame.exe ./cmd/game
```

Точный режим кросс-компиляции проверяется на зафиксированных версиях зависимостей. Итоговый файл обязательно тестируется **на Windows**, а не только успешной компиляцией. Встроенные ассеты должны позволять запускать игру из любой папки.

## 9. Требования к качеству

- Целевой FPS: 60, при этом работа меню не должна зависеть от частоты кадров.
- Логическое разрешение 1280×720; масштабирование окна без обрезки основных элементов.
- Чёткие и читаемые русские надписи; выбранный шрифт поддерживает кириллицу.
- Кнопки реагируют на левую кнопку мыши, имеют визуальную реакцию при наведении.
- Ввод обрабатывается с учётом переходов состояний; один клик не должен активировать кнопку на следующем экране.
- При отсутствии необязательного спрайта показывается заглушка; отсутствие обязательного шрифта обрабатывается понятной ошибкой или резервным шрифтом.
- Без доступа к сети и без внешних сервисов.
- Данные персонажа в MVP не изменяются и не сохраняются.

## 11. Критерии приёмки (Definition of Done)

MVP считается готовым, если:

1. В папке `dist` существует рабочий `SpellGame.exe` для Windows x64.
2. Двойной клик по `.exe` открывает окно игры с главным меню.
3. В меню видны заголовок `SpellGame`, кнопки «Персонаж» и «Выход».
4. Кнопка «Персонаж» открывает экран с изображением или заглушкой персонажа и **всеми девятью** характеристиками из таблицы.
5. Кнопка «Назад» и Escape возвращают в главное меню.
6. Кнопка «Выход» завершает приложение.
7. `.exe` работает без установки Go, без сервера, без базы данных и без ручного копирования ресурсов рядом с ним.
8. Все русские подписи отображаются корректно.
9. Исходники и инструкция сборки включены в репозиторий.
