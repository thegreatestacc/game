# SpellGame — MVP 0.1

Настольное приложение на Go + Ebitengine: главное меню, редактор характеристик
и игровой экран с текущим профилем персонажа и инвентарём.
`SpellGame-Launcher.exe` открывает лаунчер с проверкой обновлений из публичных GitHub Releases.
Пользователям не нужно настраивать токен.
Пошаговая настройка и выпуск версий: [LAUNCHER.md](LAUNCHER.md).
Техническое задание: [spellgame_mvp.md](spellgame_mvp.md).

## Запуск и сборка

Для разработки нужен Go 1.26 или новее. Ebitengine закреплён на v2.9.9.
Первое получение зависимостей требует интернета. Лаунчер проверяет GitHub перед
каждым запуском; сама запущенная игра работает локально.

```powershell
go mod tidy
go run ./cmd/game
```

Сборка Windows x64 с тестами:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-windows.ps1
```

Или вручную из корня проекта:

```powershell
go mod tidy
go test ./...
$env:GOOS = 'windows'
$env:GOARCH = 'amd64'
$env:CGO_ENABLED = '0'
go build -trimpath -ldflags="-H=windowsgui" -o dist/SpellGame-game.exe ./cmd/game
go build -trimpath -ldflags="-H=windowsgui" -o dist/SpellGame-Launcher.exe ./cmd/launcher
```

Для кросс-компиляции предусмотрен `sh scripts/build-windows.sh`.
Кросс-компиляция не заменяет проверку на Windows.

После успешной сборки запускайте `dist/SpellGame-Launcher.exe` двойным кликом.
Кнопка «Играть» проверит релиз, установит обновление и запустит игру.
Для прямого запуска игры при разработке используйте `dist/SpellGame-game.exe`.
Go и игровой движок на компьютере игрока не требуются. Шрифт и его лицензия
встроены через `go:embed`; PNG, если добавлен до сборки, также встроен.
Рабочая папка не влияет на загрузку ресурсов. При распространении сохраняйте
`FONT-LICENSE.txt`, который скрипт кладёт рядом с EXE (для работы игры файл не нужен).

## Управление

- «Персонаж» — профиль Арканиста, класс Маг, уровень 1.
- «Играть» — текущие имя, класс, уровень, девять характеристик и инвентарь
  на 12 ячеек. Значения учитывают правки в меню «Персонаж». При первом запуске
  инвентарь пуст; получение и использование предметов пока не реализованы.
  Стартовый персонаж — пиксельный путешественник в простой льняной рубахе,
  штанах и обуви, без оружия и брони. Просмотр вращения состоит из восьми
  исходных ракурсов с непрерывной интерполяцией формы и текстур на каждом
  обновлении: 480 промежуточных шагов за полный оборот длительностью 8 секунд.
  Это интерполяция 2D-спрайтов, поэтому мелкие детали могут слегка меняться
  между ракурсами; полноценная 3D-модель пока не используется.
  Анимация обновляется игровым циклом, независимо от частоты отрисовки.
- «Назад» или Escape — главное меню.
- «Выход» или закрытие окна — завершение приложения.
- Кнопки активируются левой кнопкой мыши по нажатию.

Рядом с каждой из девяти характеристик есть кнопки «−» и «+»: один клик
изменяет значение на 1 (для процентов — на 1 процентный пункт).
Для HP и MP меняется максимум и на столько же текущее значение, с ограничением
от нуля до нового максимума. Минимум максимального HP — 1; остальные минимумы — 0.
Шанс критического удара ограничен 100%, скорость — 999%, целые характеристики — 9999.
Изменения сохраняются при возврате в меню, но сбрасываются после закрытия игры.

Окно можно масштабировать;
логическая область 1280×720 сохраняется. Игра использует 60 обновлений в секунду
и вертикальную синхронизацию; фактическая частота кадров зависит от дисплея.

## Исходники и ресурсы

- `cmd/game` — запуск и сообщение об ошибке Windows.
- `cmd/launcher`, `internal/launcher` — окно лаунчера и запуск проверенной игры.
- `internal/updater` — доступ к публичным GitHub Releases и проверка обновлений.
- `.github/workflows/release.yml` — сборка и публикация версии по Git-тегу.
- `internal/app` — цикл игры, единый снимок ввода, переключение экранов.
- `internal/animation` — сопоставление деталей спрайтов и непрерывная анимация поворота.
- `internal/screens` — главное меню, профиль, игровой экран с инвентарём и тесты переходов.
- `internal/ui` — кнопки, текст, панели и декоративный фон.
- `internal/domain` — модель персонажа, не зависит от движка.
- `internal/assets` — встроенный Go Regular с кириллицей и лицензией BSD.

Портрет, спрайт на локации и вращение используют встроенный `internal/assets/sprites/starter-pixel-turntable.png`
(4 столбца × 2 строки: фронт, 45°, правый бок, 135°, спина, 225°, левый бок, 315°).
Спрайты созданы встроенным imagegen; запрос сохранён в `images/characters/starter-pixel-prompt.txt`.
В меню «Персонаж» и на локации показывается первый кадр. Старый спрайт с бронёй
не переопределяет стартовый облик. При отсутствии или повреждении спрайтов
используется процедурная заглушка. Ошибка обязательного шрифта возвращается
с пояснением и показывается в диалоге Windows.

Справочник движка: https://ebitengine.org/en/documents/2.9.html

## Проверка готовности

Зависимости загружены, `go.sum` создан. Сборка Windows x64 выполнена:
`dist/SpellGame-Launcher.exe` (лаунчер) и `dist/SpellGame-game.exe` (игра).
Команда `go test ./...` проверяет навигацию, анимацию и механизм обновлений.
Отрисовка окна лаунчера проверена на Windows. Первый GitHub Release ещё
нужно опубликовать тегом по инструкции из LAUNCHER.md.
Дополнительно проверьте на Windows:

1. Запуск EXE из другой рабочей папки без файлов ресурсов рядом.
2. Читаемость русских надписей и наличие всех девяти характеристик.
3. Переход в профиль, возврат кнопкой и Escape несколько раз подряд.
4. Удержание мыши не вызывает повторных действий.
5. Изменение размера окна не обрезает интерфейс.
6. Завершение кнопкой «Выход» и системной кнопкой закрытия окна.
7. «Играть» открывает текущий профиль и пустой инвентарь; «Назад» и Escape
   возвращают в главное меню. Правки характеристик видны на игровом экране.

Навигационный тест: `go test ./...` (для пакетов движка нужна графическая среда).
Доменная модель отдельно: `go test ./internal/domain`.


## Первая локация (v0.3.0)

«Играть» в главном меню открывает лесную поляну. WASD перемещает статичный спрайт персонажа, Escape и «В меню» возвращают в меню. Камера следует за персонажем; скорость учитывает характеристику скорости движения. Диагональ не ускоряет движение. По периметру поляны установлены границы ходьбы. Интерактивных предметов и врагов пока нет.

Фон: internal/assets/locations/clearing.png, создан встроенным imagegen. Направление графики: пиксельная фэнтезийная поляна, зелёная трава, охристые дорожки, тёмный лес по краям, вид сверху под углом. Референс: https://store.steampowered.com/app/3546610/ . Исходное изображение является самостоятельной иллюстрацией, а не копией ассетов игры.

Для проверки локальной версии запускайте dist/SpellGame-game.exe. Лаунчер загружает опубликованный GitHub Release; локальные изменения появятся в нём после публикации нового тега.

## Дыхание в покое (v0.3.2)

На локации неподвижный персонаж дышит: локально двигаются грудь, плечи и руки, ноги остаются на месте. Цикл — 4 секунды. Анимация включается и затихает за 0,2 секунды при остановке и начале движения. При упоре в границу персонаж считается неподвижным. Используется деформация сетки текущего пиксельного спрайта с nearest-neighbor отрисовкой; координаты персонажа и камера от дыхания не меняются. Время анимации считается в Update при 60 обновлениях в секунду.

## Ходьба (v0.3.3)

При фактическом перемещении на локации включается фронтальная анимация ходьбы: попеременное движение ног, противофаза рук и лёгкое покачивание корпуса. Направление WASD пока не меняет ракурс. Полный цикл двух шагов занимает 0,7 секунды. При остановке ходьба затихает и возвращается дыхание; при упоре в границу и нулевой скорости персонаж остаётся в покое. Используется деформация пиксельного спрайта в игровом движке, новые растровые ассеты не требуются.

## Направление движения (v0.3.4)

На локации персонаж использует восемь ракурсов: S — лицом к зрителю, W — спиной, A/D — левым/правым боком; сочетания клавиш выбирают диагональные ракурсы. После остановки сохраняется последнее направление. Ракурс определяется фактическим перемещением после ограничения границами поляны, поэтому при скольжении вдоль границы персонаж смотрит вдоль неё. Дыхание и ходьба применяются к выбранному спрайту без сброса цикла. При нулевой скорости или полном упоре в границу направление сохраняется.

## Волшебник-наставник (v0.3.5)

На перекрёстке стоит загадочный волшебник. Игрок появляется южнее него. На расстоянии до 105 единиц над NPC отображается «нажмите E». E открывает разговор с подсказками о движении на WASD и действии на E. Во время разговора движение приостановлено; E или Escape закрывает диалог, следующий Escape возвращает в меню. Зажатая E не вызывает повторных открытий: ввод обрабатывается по фронту нажатия. NPC имеет небольшую область столкновения и рисуется с учётом положения игрока по вертикали.

Спрайт создан встроенным imagegen: internal/assets/sprites/tutorial-wizard.png. Запрос: images/characters/tutorial-wizard-prompt.txt.
